# DotDotDone

### The forever simple time tracker.

Most productivity tools start simple.

Then they add projects.

Then tags.

Then goals.

Then dashboards.

Then reports.

Then AI.

Eventually, the timer becomes the least important part of the product.

DotDotDone exists to do one thing well:

**Track time with as little friction as possible.**

## Why?

Sometimes you don't need another productivity system.

You already have:

* Excel
* Notion
* Obsidian
* Paper notebooks
* Google Sheets
* Your own way of organizing work

You just want to know:

> What did I spend my time on?

DotDotDone helps answer that question.

## Principles

### Simple first

Open the app.

Describe what you're working on.

Start the timer.

That's it.

### No forced structure

Use whatever naming convention works for you.

Examples:

```text
Review proposal

[Client A] Landing page redesign

Poker study

Write blog post

Deep work
```

DotDotDone doesn't force projects, categories, or workflows.

### Your data stays yours

Export your history as CSV.

Analyze it in Excel.

Generate invoices.

Create reports.

Build your own workflow.

### No productivity guilt

No streaks.

No dying trees.

No gamification.

No productivity scores.

Just a record of where your time went.

### Forever simple

Every feature must justify its existence.

If a feature makes time tracking harder, more complicated, or more distracting, it probably doesn't belong here.

## Current Features

* Focus timer
* Time logging
* Session history
* CSV export
* Browser notifications
* Calendar-based history navigation

## Roadmap

Only features that strengthen the core experience:

* Cross-device sync
* Better notifications
* Improved history navigation

No project management.

No task management.

No unnecessary complexity.

## Built For

Anyone who wants a fast, frictionless way to track time.

Nothing more.

Nothing less.


## Getting Started

### If you want to use it

Click here: https://dotdotdone.recaptured.in/

### If you want to tinker or contribute to the source

#### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

#### Installation

1. Clone the repository
```bash
git clone <repository-url>
cd DotDotDone
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:8080`

#### Build for Production
```bash
npm run build
```

The production build will be available in the `dist` folder.

#### Preview Production Build
```bash
npm run preview
```
